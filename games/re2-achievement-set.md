# Resident Evil 2 (classic, GOG) — achievement set (draft v1)

59 achievements + 1 platinum. Inspired by the RetroAchievements PS1 / N64 /
GameCube sets and the RE2 (2019) list; names and wording are our own.

Status: ✓ live · ◐ needs only an item ID (inventory is mapped) · ○ needs a
new memory value. Details from the 1998 game marked † need confirming in play.
