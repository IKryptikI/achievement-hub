Download

The desktop app finds your games and installs the overlay into them. Both are in one download.

Linux

AppImage, works on most distributions. Games running through Proton, Wine, Heroic, Bottles or Lutris are supported.

Download for Linux

Windows

Windows 10 or 11, 64-bit.

Download for Windows

All releases and checksums are on GitHub. Or build it yourself from the source code.

Installing

Linux

  1. Download the .AppImage file.
  2. Make it runnable: right-click → Properties → Permissions → "Allow executing", or run chmod +x AchievementHub*.AppImage.
  3. Open it. It scans Steam, Heroic, Bottles and your game folders.

Windows

  1. Download and run the installer.
  2. If SmartScreen warns you (new apps without a paid certificate do), click "More info" → "Run anyway".
  3. Open Achievement Hub from the Start menu.

Adding a game

  1. In the app, open Add Game. Supported games show their achievement count; games with anti-cheat are blocked.
  2. Click Install overlay. The app adds a small file next to the game (and, on Linux, a setting so Wine loads it). Nothing else about the game changes, and Uninstall puts everything back.
  3. Launch the game the way you always do. A welcome pop-up means it's working.
  4. Open the overlay any time with Shift+F2, or the Xbox button (Back+Start also works).

Connecting your account

  1. Create an account and open Account → Link the app to get a code.
  2. In the app, open Friends and enter the code. Your Gamerscore and unlocks now appear on your profile, and your friends appear in the overlay.
