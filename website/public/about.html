About

Achievement Hub started with a simple wish: earning achievements in the classic PC versions of games that had them on console, like Resident Evil, Silent Hill and Fallout 3. It's a free, open-source project for players who love older games.

How it works

  • The overlay loads inside the game and reads the game's own memory (never writing to it) to see when you earn something. It draws pop-ups and a dashboard styled after the Xbox 360.
  • The game database holds each game's achievement list and the rules that unlock them. It's public on GitHub, so anyone can add or improve games.
  • Record mode lets players map achievements by playing: press a button right after earning one, and the overlay works out what changed in the game. Shared findings go into the database for everyone.
  • No anti-cheat games, ever. Games with anti-cheat are detected and blocked, so nobody risks a ban.

Open source

The code is on GitHub under the GPL-3.0 license: use it, study it, change it, and share your changes under the same terms.
